# LocalFix – Local Household Services Marketplace

## 1. Project Vision

LocalFix aims to provide a convenient platform that connects customers with local service providers for household services such as plumbing, electrical repairs, carpentry, and cleaning.

## 2. Problem Statement

Finding reliable local service providers can be difficult. LocalFix aims to make discovering and accessing household services easier through a single platform.

## 3. Objectives

- Help customers discover household services.
- Display service and provider information.
- Simplify the process of finding suitable local professionals.
- Provide a convenient platform for customers and service providers.

## 4. Navigation Flow

The planned application navigation flow is:

**Login → Home/Dashboard → Service Listing → Service Details → Profile**

This represents the initial planned navigation. The screens and flow will be refined as the team develops the application and finalizes its wireframes.

## 5. Technology Stack

- **Frontend:** Flutter
- **Programming Language:** Dart
- **Version Control:** Git and GitHub
- **Development Environment:** Visual Studio Code
- **Testing Platform:** Google Chrome

## 6. Project Status

**Week 1 – Initial Setup**

The initial Flutter project has been created and tested successfully in Google Chrome. The GitHub repository and project documentation have been set up. Wireframes, user journeys, and further application development are ongoing team activities.

## 7. Getting Started

1. Install Flutter and Dart.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Run `flutter pub get`.
5. Run `flutter run -d chrome` to launch the starter application in Chrome.

## 8. Team Project

LocalFix is a team project focused on planning and developing a local household services marketplace. Team members contribute to the app proposal, user journeys, wireframes, and development setup.
